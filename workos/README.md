# WorkOS 中文在线工作台 v0.6

**打开地址（GitHub Pages 部署成功后）：**
https://tanzhi6269330-star.github.io/shopping-intelligence/workos/

## 架构说明
- 独立放在购物系统仓库的 `workos/` 子目录，只复用已经运行的 GitHub Pages 发布流程。
- **不修改购物网站首页和购物筛选业务逻辑。** 后续能创建新仓库时，建议迁移 WorkOS 到单独仓库。
- 纯静态 HTML/CSS/JavaScript，免安装、中文界面，家中和办公室均可访问。
- **没有在线账户和跨设备云同步**。任务、知识、审视记录存于每个浏览器自己的 localStorage。不同电脑的数据可通过导出 JSON、导入 JSON 手动迁移。
- **没有 ChatGPT API**：生成执行和质检提示词，手动复制到 ChatGPT 使用。网页不会自动上传任务记录或文件。

## 功能
工作任务登记与状态、执行与质检提示词、知识记录、月度金额差异核对、每三步建设复审提醒及 JSON 备份恢复。

## 验收与限制
- `tests/workos.test.mjs` 为基础静态与脚本语法安全检查，不能替代浏览器人工验收。
- 模拟材料可用于测试；真实组织内部资料按使用单位规范另行审批。
- GitHub Pages 为公开站点，**不要把任何模拟或真实业务文件提交到仓库**。
- 当前 GitHub 仓库共享托管的是网页代码而非工作数据；购物应用不读取 WorkOS 的 localStorage 键值。

## 三步审视
每完成 3 个工程步骤进行一次上下游双向审查：向上验目标与证据，向下验下一步接口和风险。自动提醒不意味着 AI 在后台自动替用户完成审查。
