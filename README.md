# 智能购物决策系统（中文在线版）

这是一个直接在网页浏览器中使用的多平台商品候选与人工核验工作台。已适配 **京东、淘宝/天猫、拼多多、闲鱼、1688 和盼之代售** 的搜索或官网入口。

## 功能边界

- 可以：填写购物需求、设置预算、打开六个平台的搜索/官网入口；添加商品候选链接、标价、费用、规格和核验备注；保守筛选普通商品，独立隔离批发、二手及游戏账号候选；导出 CSV 或 JSON，或从 JSON 恢复。
- 不可以：直接跨平台自动抓取实时价格、自动登录或下单、保证账号交易安全。网页不提供实时全网最低价认证。
- 隐私：商品数据只保存在当前设备的浏览器本地存储，没有云端账户或跨设备同步。不要录入身份证、密码、付款信息和订单隐私。

## 部署

首页采用**单文件 `index.html`**，不依赖 Python、Windows BAT 或外部 CSS/JS 文件。GitHub Actions 工作流位于 `.github/workflows/deploy.yml`。

首次部署需要仓库管理员到 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。之后对 `main` 的提交会执行 `node --test tests/*.test.mjs`，并在测试通过后上传和部署静态网站。

待 Pages 成功部署后，地址通常是：
https://tanzhi6269330-star.github.io/shopping-intelligence/

请以仓库 Settings → Pages 显示的地址和 Actions 成功记录为准，**不要把预计网址当作已上线**。

## 真实验收

浏览器端需要检查：页面加载、六平台入口、录入候选、未知运费隔离、规格与费用确认后的比较、1688/闲鱼/盼之专项分组、JSON 导入导出、CSV 导出、手机端布局。自动化离线测试不代替这些真实验收。
