# 智能购物决策系统 V0.7（对话推荐优先）

在线地址：https://tanzhi6269330-star.github.io/shopping-intelligence/

## 如何使用
直接在首页聊天框中说出你的购物需求，例如“帮我找100元以内带麦的游戏耳机”。系统可以用自然语言继续追问预算、用途、有线无线等影响选择的关键条件；后续输入“再便宜一点”“80元以内”“不要漫步者”等，只更新对应维度，保留其他已知要求。

没有指定品牌时，先查研究资料中的跨品牌型号候选；这些候选附公开来源链接、历史参考价说明以及尚待核验的风险。对于暂不支持的品类，系统只提供相关评测和平台搜索入口，不会编造榜单或品牌排名。用户也可自己打开京东、淘宝、拼多多、1688、闲鱼、盼之代售。

## 很重要的实际能力边界
**当前是静态网页上的规则化对话与小型来源研究样板，不是已接通大模型推理和全网实时自动搜索的 ChatGPT 替代品。**

- 可以：自然语言输入、关键追问、上下文预算/用途/品牌继承、品牌排除、评测来源链接、有限品类型号研究、跳转外部检索。
- 暂不能：自动读取六平台实时商品、确认当前到手价、自动总结全网最新博主观点、认证卖家或游戏账号安全、自动下单。
- 推荐排序是研究资料相关性，不是性能/性价比经实测的确定性排名。
- 对话数据保存在当前浏览器 localStorage，不跨设备同步；不要输入密码、身份证、Cookie、支付或订单敏感信息。

## 工程结构
- index.html：中文对话首页。
- chat/recommendation.mjs：纯函数会话规则、关键问题、证据候选、外部搜索入口。
- classic/index.html：旧版手动商品录入与核验工作台。
- tests/chat.test.mjs：多轮对话、预算继承、来源与推荐规则测试。
- tests/chat_browser_smoke.py：GitHub 云端真实 Chrome 交互验收。
- docs/31_开源组件选型审计.md：Vane、SearXNG、RSSHub、Crawl4AI、LangGraph 的能力、许可和成本风险。
- docs/32_对话推荐和证据标准.md：推荐准入、证据质量、问题策略。
- docs/33_第十一次双向复审.md：31—33步的双向审视及34—36步计划。
- .github/workflows/deploy.yml：合并至 main 后自动测试与 GitHub Pages 发布。
