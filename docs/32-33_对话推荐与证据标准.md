# 第32—33步：推荐研究与多轮对话引擎

## 第32步 推荐证据模型（已建立最小版本）

推荐分为两个相互独立的层次：

1. **型号研究**：公开评测来源 → 品牌/型号 → 适合用途及局限。当前仅以2026年10月的 RTINGS 与 Tom's Hardware 游戏耳机横评提供示例。
2. **购买报价**：具体平台 + SKU + 全部费用 + 销售状态 + 获取时间 + 风险核验。当前真实平台自动采集未通过，因此**不得**把型号研究说成中国实时价格推荐。

**推荐质量规则**：
- 有明确品牌限制，优先遵守；无品牌限制，主动跨品牌发现。
- 至少给出每个具体型号的评测来源和优缺点；广告、榜单流量、销量排行只作为候选发现信号，不直接算作性能证据。
- 若预算、连接方式不匹配或者没有可靠报价，必须标记未核验。
- 专业来源相互矛盾时展示分歧；同源转载不算多个独立证据。
- 不将海外美元报价直接换算为中国到手价；不同销售版本/型号要区分。
- 对盼之游戏账号不套用耳机的推荐模型，安全核验优先。

当前示例数据：
- HyperX Cloud III 有线：RTINGS 预算游戏耳机评测、Tom's Hardware 2026-10-08 游戏耳机评测；
- SteelSeries Arctis Nova 1：Tom's Hardware 2026-10-08 评测；
- Turtle Beach Atlas 200：Tom's Hardware 2026-10-08 评测。
**注意**：示例型号均未经过中国市场实时价格核验，不保证用户的人民币预算能买到；并非所谓“全品类推荐引擎”。

- https://www.tomshardware.com/peripherals/gaming-headsets/best-gaming-headsets

## 第33步 对话交互（第一期已实现）

- 首页改为自由输入对话框，支持句子里解析品类、预算、用途、是否带麦、有线/无线、是否接受二手、指定/排除品牌和平台。
- 单轮追问只问最影响推荐结果的缺失条件；后续“便宜点”“排除二手”“只要无线”继承其他条件。
- 侧栏持续显示购物限制、可复核型号/评测出处与跨平台搜索入口。
- 用户数据存浏览器 localStorage，不上传 GitHub。
- 原核验工作台保留在 `/classic/`；另有 `/workos/`，没有合并成同一功能。
- Selenium 实测脚本 `tests/chat_browser_smoke.py` 会在 GitHub Pages 发布成功后运行。

## 尚未具备的能力（不可误报）
- 通用自然语言模型推理、跨品类自动发现品牌、新评测实时搜索、真实电商商品自动采集和到手价。
- 本期仍是**确定性规则对话原型**。用户最终目标是真正的 AI 选品助手，需要后端模型推理/搜索引擎及商品数据提供方。
- GitHub Pages不能安全地把模型密钥放在前端；任何第三方模型或搜索 API 密钥只能放服务端 Secrets 中。
