## 向上审查（之前做错了什么）
1. 旧版要求填写价格/运费/SKU，违背用户随口描述购物需求的初衷。已将其迁移到 classic/ 作为可选专业核验工具。
2. 跨平台商品抓取先前实际测试为0条可核验商品，网页前端不能冒充拥有自动全网搜索能力，继续坚持不虚构。
3. 用户要的不止最低价，还需要不指定品牌时的主动横向探索、专业测评、真实口碑、差异化追问和来源证据。

## 向下审查（还缺哪些关键能力）
1. 目前无LLM后端、无可实时调用的通用网页搜索接口；中文对话由有限规则驱动，不等同于 ChatGPT 完整语义理解。
2. 研究候选只覆盖少量耳机型号，其他品类只可缩小需求和打开评测/平台搜索；绝对不能称为成熟推荐引擎。
3. 只显示文章历史价/范围，不可当作当前商品挂牌价或实际到手价；缺口不能靠主观权重弥补。
4. 社区文章及博主可能存在营销和利益关联。实测、用户反馈、榜单、品牌宣传要分级，引用数量相同来源不等于多方验证。
5. 免费 GitHub Pages 不能安全持有 AI API 密钥。真正的“自动调查评测并全平台找货”需经授权/可运行的搜索服务和模型推理，且必须做真实访问覆盖率与费用验收。
6. 旧版手工核验和 WorkOS 子站必须保留，新增对话首页不能破坏已有服务。
