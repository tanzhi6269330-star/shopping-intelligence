# 第34步：免费无密钥搜索与社区评测证据审查

## 实验信息（2026-11-06）
- 工作流：[无密钥搜索实验 #42231292639](https://github.com/tanzhi6269330-star/shopping-intelligence/actions/runs/42231292639)。
- 使用 `tavily-python` 的 `TavilyClient()` 无密钥模式，在 GitHub Actions 运行，两次公开商品评测查询均实际返回5个链接，总计10条候选来源。
- 真实原始 JSON 在工作流 Artifact（默认保留14天），包含标题与网址，不含账号、Cookie、用户购物隐私或价格数据。
- **结论：免费 GitHub 运行环境能够查询到搜索引擎候选网页，不等于获得可重复不限额的公共 API，更不等于已支持实时六平台价格。**

## 真实搜索样本质量（只按标题与域名判断）
查询 A：百元有线游戏耳机横评。结果覆盖知乎、B站、博客、新闻报道和耳机专题网站。其中标题带“品牌品质优选”“无广实测”等都不是中立性的可靠证明；媒体文章可能含营销赞助，不能按排序直接推荐品牌。
查询 B：无线鼠标。结果覆盖 B站多个横评视频、知乎、快科技等。标题往往是博主自称“实测”“无广”，需要进一步检查测量方法、利益关系、实际使用场景、原型和样本时间。

新增 `chat/source-screening.mjs` 和 `tests/source_screening.test.mjs`：
1. 仅采纳合法 HTTPS 来源链接，分类专业测试机构/社区/媒体/其他。
2. 标题营销词风险提示，“无广”等只是作者声明，**不能**自动认证为独立评测。
3. 去重相同文章 URL，不把同平台同篇重复结果当作独立论证。
4. 所有来源初始状态都是 `independentVerified=false`、`priceVerified=false`、`brandRecommended=false`。
5. 来源筛选只是人工核验优先级；没有核对正文、测试方法、具体型号、发布时间和价格，不给高性价比结论。

## 稳定性与免费成本
GitHub Actions 是运行环境，Tavily 是另外一家公司提供的搜索服务。无密钥模式有共享配额/风控/服务策略变化风险，不能当作稳定生产 API 或承诺免费无限量。若要支持网站每个用户消息调用，需要另行部署带安全速率限制、缓存、身份与配额保护的后端（GitHub Pages 单独做不到）。

## 部署与风控保护
`.github/workflows/research-probe.yml` 已改成仅手动触发，防止每次推送新代码自动对已触发安全验证的1688等站点重复试探。
无密钥 Tavily 实验工作流也不应每次改动代码自动大量运行；下一阶段采取单次小样本验收，保留真实证据后再决定引入方式。
