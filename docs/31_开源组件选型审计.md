# 第31步：高星开源组件核查（2026-11-06）

## 系统目标
用户无需填写商品表单，只说一句购买需求。系统应通过对话识别商品品类、预算、用途、可接受新旧、指定/排除品牌等；**不指定品牌时主动发现有证据支持的品牌和具体型号**，按性价比、使用体验及风险进行研究，给出出处，再寻找真实店铺与到手价。查不到的信息不得编造。

## 项目适配审查

| 项目 | GitHub / 许可 | 可复用能力 | 本阶段裁决 |
|---|---|---|---|
| Vane（原 Perplexica） | https://github.com/ItzCrazyKns/Vane · MIT | 带出处的问答、搜索模式、本地/云端模型 | 借鉴 UI 与架构，不直接自托管完整服务 |
| SearXNG | https://github.com/searxng/searxng · AGPL-3.0 | 多搜索引擎发现评测、用户讨论 | 后期仅评估合规自托管；公共实例的 JSON 接口常被关闭 |
| RSSHub | https://github.com/DIYgod/RSSHub · AGPL-3.0 | 追踪测评博主、B站、商品讨论与好价文章 | 后期按类别订阅，不直接复制其代码 |
| Crawl4AI | https://github.com/unclecode/crawl4ai · Apache-2.0 | HTML→结构化证据与文章摘要 | 后期优先用于合法公开文章，非通行证 |
| LangGraph | https://github.com/langchain-ai/langgraph · MIT | 长期状态化 Agent 和分支工作流 | 当现有轻量会话状态不足时再引入 |
| Meilisearch CE | https://github.com/meilisearch/meilisearch · MIT 社区版 | 文章/品牌型号检索，快速过滤 | 暂不引入；需要足够规模的可信证据库 |
| Tavily Python | https://github.com/tavily-ai/tavily-python · 客户端库 | 可试验 keyless 搜索 | 只当技术候选，不能承诺无限免费/不要求服务账号 |

许可证核查重点：SearXNG、RSSHub 为 AGPL-3.0，后续若修改并提供网络服务，应先评估对应网络服务的源代码义务；Vane、LangGraph 为 MIT；Crawl4AI 为 Apache-2.0。特别注意：开源代码免费不意味着云推理、爬虫代理、搜索API、主机和网络访问免费。

## 推荐质量优先于盲目榜单

一、专业实测：独立测试方法、样本大小、产品精确版本、时间与适用场景。
二、社区横评：可能有推广/联盟关系；区分原始用户体验和二次转述，不以阅读量或点赞直接决定好坏。
三、普通用户反馈：重点研究长期故障、兼容性和售后，而非看评论数量。
四、榜单：用于发现品牌型号，不直接转成推荐排名。
五、品牌规格：用于核实具体 SKU，不用于证明性价比。
六、店铺价格：必须核实实际购买数量、规格、优惠资格、运费、服务费、成色/账号风险；不得与文章历史价格混同。

推荐结果结构：型号、品牌、品类、用途、价格证据、来源 URL、来源类型、发表日期、利益关系（已知/未知）、风险与负面评价、库存/规格、核验状态。无独立证据则归为“待研究”，不能给确定性 TOP1 结论。

## 本阶段技术实施

- 纯 JavaScript 的对话状态与规则推演，不需要额外费用或 AI 密钥；
- 内置极少量2026年公开可查的**耳机类研究线索**，每个条目直接指向出处并显示“非实时价”；
- 品类未知或证据不足时，展示具体的外部评测/平台检索入口，不虚构已发现的商品；
- 未来才接入带实际搜索能力、授权合规、可审计来源的在线后端；严禁在 GitHub Pages 前端暴露 API 私钥；
- 旧版手工录入保留在 classic/，但不再占据首页。
